## Acceptance

- pulse-owns-check: no two packages' owns overlap; every file under frontend/src is owned, frozen or integrator-listed; every file a package deletes is in its owns; every preClaim names a later owner; anchoredBy agrees with verify:gates --list-anchors; it is the one glob expander every other tool imports
- pulse-merge-check refuses a branch that touches a path its package does not own, raises a budget, carries a fixture that fails pulse-fixture-check, or touches an anchored file without a green verify:gates run on the squashed tree
- pulse-sync <id>: clears dead locks and a stray preview, restores the fixed path list (three bundles, catalog.ts, scripts/data/*.json, the paths of the package's own shared.patch), asserts git status shows owned paths only, merges pulse-redesign (or switch -C for re-use), npm ci if the lockfile changed, re-applies the COMMITTED hand-in files and stops with status blocked if one no longer applies. Test: a merge into a slot with an applied patch succeeds through it and fails without it
- pulse-i18n check / apply / revert enforce PLAN.md 4.4 rules (a)-(f): add by namespace, change/remove by consumers over pulse-redesign and all pulse/* tips (the gate's own scan, imported), untranslated required exactly when en or de equals hu and written to scripts/data/i18n-untranslated.json, a removed exempted key drops its entry, patch read from the branch HEAD
- pulse-i18n: an empty patch leaves the three bundles byte-identical (git diff empty); flat dotted top-level keys stay flat (a test sets an achievement.* key); CRLF line endings preserved; identical key order
- pulse-variants check / apply / revert: refuse a delta whose useElementVariant read is not in a file the package owns (the gate's reader scan, imported); write catalog.ts and scripts/data/elements-dormant.json; accept lane ids as well as package ids (as does pulse-i18n)
- pulse-fixture-check: a fixture is a list of pointer edits over a recording of the same endpoint; fails on a key, a type or an enum value no recording of that endpoint has
- pulse-progress: sync folds .pulse/status/*.json into .pulse/progress.live.json idempotently and atomically; snapshot writes docs/pipeline/pulse/progress.json from it; files are generated from work-packages.json; sync --from-snapshot rebuilds a lost live file
- pulse-ledger prints hook calls, mutation calls, doors, role / aria attributes and the counts of focus-visible:, useMotionSafe( and motion-reduce: present at the merge base and missing now, for the owned paths
